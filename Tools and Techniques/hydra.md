# Hydra

## Overview
- Hydra is a fast and flexible password auditing tool.
- It is used to test authentication systems for weak credentials.

## Key Concepts
- Hydra supports multiple protocols such as SSH, FTP, HTTP, HTTPS, SMB, RDP, and Telnet.
- Commonly used in penetration testing to identify weak login credentials.
- Hydra automates login attempts using username lists, password lists, and combined credential lists.

## Common Options
- `-l` - Single username
- `-L` - Username wordlist
- `-p` - Single password
- `-P` - Password wordlist
- `-t` - Number of parallel threads (e.g -t 4)
- `-v` - Verbose output

## Relevance
- Helps identify weak passwords and authentication weaknesses.
- Supports password security assessments.
- Reinforces the importance of strong passwords and multi-factor authentication.
