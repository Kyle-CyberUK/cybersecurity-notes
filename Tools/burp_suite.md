# Burp Suite

## Overview
- Burp Suite is a popular web application testing tool used for intercepting, inspecting, and modifying HTTP/HTTPS traffic.

## Key Concepts
- Commonly used for penetration testing, bug bounty hunting, and security researching.
- Available in community edition (free) and professional edition (paid).
- Burp Suite captures GET and POST requests, headers, cookies, and parameters.
- Burp Suite installs its own CA certificate to inspect HTTPS traffic.
- Allows encrypted requests and responses to be viewed in plaintext.

## Core Components
- **Proxy** - Intercepts browser traffic between the client and the web server.
- **Target** - Displays website structure, discovered endpoints, and web application mapping.
- **Repeater** - Resends and modifies HTTP requests manually.
- **Intruder** - Automates attacks using payload lists.
- **Decoder** - Encodes and decodes data formats.

## Relevance
- Burp Suite is an essential tool for penetration testing and bug bounty hunting.
- Burp Suite is commonly used to test for SQLi, XSS, authentication flaws, and access control issues.
